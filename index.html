AI Chat Assistant for ERPNext — Gurujan Chat Bot

A ReAct-style AI agent built as a native Frappe app — chats with users over live ERPNext data and explains how the system itself works, using the Model Context Protocol (MCP) to call tools grounded in real data instead of guessing.

  • Architecture: ReAct agent loop with JSON-constrained decisions — each turn picks its own next tool call (search, read, count, lookup) before answering
  • MCP tool suite: 10 custom tools — record search/read/count, live doctype schema lookup, linked-record traversal, semantic doc/code/catalog search, and permission-checked create/update with required user confirmation
  • Models: runs against local Ollama models (qwen2.5-coder) by default, or Claude / OpenAI-compatible cloud APIs
  • Retrieval: semantic re-ranking of keyword search results with local embeddings (nomic-embed-text) across Frappe/ERPNext docs, the app catalog and source code
  • Reliability: brace-depth JSON extraction, a regex-checked false-claim guard on the fallback path, and Frappe's own permission system enforced on every tool call
